# Core Java Library System

A clean Core Java project demonstrating:
- Object-Oriented Design
- Interfaces & implementations
- File-based persistence
- Unit testing with JUnit 5

## Features
- Add books to a library
- Borrow books with validation
- Prevent duplicate ISBNs
- Persist data using a file
- Unit-tested business logic

## Technologies
- Java 21
- JUnit 5
- Plain Java (no frameworks)

## Project Structure
- `model` – domain objects
- `service` – business logic
- `repository` – file persistence
- `test` – unit tests

## Purpose
This project is part of my Core Java learning path,
preparing for Spring Boot and backend development.
